Calculation Principles & Assumptions

Attendance Shortage Formula:

If attendance < threshold, the smallest number of future consecutive classes $n$ you must attend without missing is calculated as: n = ⌈(Threshold × Conducted - 100 × Attended) / (100 - Threshold)⌉

Safe Bunk Formula:

If safely above threshold, the number of classes $m$ you can safely miss without dropping below threshold is: m = ⌊(100 × Attended - Threshold × Conducted) / Threshold⌋

Key Assumption: All upcoming classes carry equal credit weight. College rules apply strictly on session counts without rounding up unless explicitly permitted by university statutes.

Campus360 Formula Guide & Reference

1. Attendance Calculations

Attendance Percentage: (Attended Classes ÷ Conducted Classes) × 100

Classes Needed to Reach Threshold: If attendance is below mandatory threshold $T$ (e.g. 75%), the minimum subsequent classes $n$ that must be attended consecutively is:

n = ⌈(T × Conducted - 100 × Attended) / (100 - T)⌉

Safe Bunk Allowance: If safely above threshold, the number of classes $m$ you can safely skip without falling below $T$ is:

m = ⌊(100 × Attended - T × Conducted) / T⌋

2. Semester GPA (SGPA)

Calculated as credit-weighted average of grade points obtained in all enrolled courses:

SGPA = Σ (Course Credits × Grade Points) / Σ (Course Credits)

3. Cumulative Grade Point Average (CGPA)

Calculated across all completed semesters weighted by earned semester credits:

CGPA = Σ (Semester Credits × SGPA) / Σ (Semester Credits)

4. Syllabus Completion Rate

Tracks unit and topic milestones against total syllabus chapters:

Subject Completion % = (Completed Topics ÷ Total Topics) × 100
